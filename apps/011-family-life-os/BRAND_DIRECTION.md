# Family Organizer — Brand Direction v0.1

Status: DIRECTION LOCKED, PUBLIC NAME OPEN
Date: 2026-08-18

## Brand job

The brand must make a parent think: **This will make our everyday life calmer.**

It must not communicate surveillance, parenting judgement, childish gamification, corporate project management, generic AI magic or yet another shared calendar.

The product promise is functional calm: incoming family information becomes a clear, shared plan with less manual administration.

## Brand personality

Primary traits: calm, capable, warm, trustworthy, clear, discreet, modern.

Secondary traits: intelligent but not showy; friendly but not cute; premium but not luxury; family-oriented but not baby-oriented.

## Positioning language

Internal product thesis: `Family Life OS`.

This phrase is **not available as distinctive public positioning**, because current competitor Famiqo already publicly uses `Family Life Operating System`.

Preferred message territory:

- `Alles, was bei eurer Familie ankommt. Automatisch organisiert.`
- `Aus Elternbriefen, Nachrichten und Terminen wird euer gemeinsamer Plan.`
- `Weniger organisieren. Mehr Überblick.`
- `Familienalltag rein. Klarer Plan raus.`

Avoid generic claims such as `Der smarte Familienplaner`, `AI Family Assistant`, `Family OS` or `Die ultimative Familien-App`.

## Naming principles

A strong name should:

- be pronounceable in German and English
- be 2–4 syllables
- work without `AI`
- not be limited to calendar or chores
- not sound school/daycare-only
- not imply surveillance/location tracking
- allow a simple app-icon monogram or symbol
- pass App Store, web and trademark collision checks before locking

Naming territories to explore:

1. abstract calm coordination / flow
2. subtle household/family signal
3. Kamilunavo portfolio extension only if collision checks allow it

A `Navo...` direction is only exploratory; NAVO is already used by unrelated products, so it is not cleared.

## Names rejected / blocked in first pass

- **Family Life OS** — public positioning rejected because Famiqo uses `Family Life Operating System`.
- **Famiqo** — existing competitor product.
- **Kinora** — multiple current family/child products already use it, including a child organizer.
- **Familoop** — existing family-focused secure messaging product.
- **Kinbox** — current software plus historical family/social-network exact-term use creates needless collision risk.

## Name-lock procedure

Before selecting a public name:

1. exact App Store search
2. exact web search
3. EUIPO search
4. DPMA search
5. relevant international trademark search where practical
6. domain/social handle check
7. DE + EN pronunciation/spelling test
8. App Store subtitle test
9. icon/wordmark test

No name is considered cleared merely because an exact App Store hit is absent.

## Visual identity direction

Core metaphor: **many loose pieces becoming one organized family plan**.

Useful abstract motifs:

- converging paths
- grouped tiles becoming one shape
- soft orbit around a center
- incoming sheet transforming into an organized action
- connected but distinct household members

Avoid literal cartoon house + heart, family stick figures, robot/AI sparkle, calendar page, checklist and location-pin primary marks.

## App icon direction

### Preferred: `Gather -> Order`

A bold, simple symbol with 2–3 rounded pieces flowing into one centered organized form.

Requirements:

- recognizable at small size
- no text or tiny details
- strong silhouette
- works in light, dark and tinted icon appearances
- can benefit from modern iOS icon rendering without depending on glass effects

### Alternate: `Shared Orbit`

Three subtle nodes/forms around a calm center. Risk: can become too generic/social-network-like.

### Rejected: `House + Checkmark`

Too generic and reads as chores/home management.

## Color direction

Final brand palette is not locked.

Preferred mood:

- one calm primary hue, likely muted blue/indigo territory
- one warmer supporting hue, e.g. amber/coral territory
- family-member accents remain separate from brand primary
- neutral system backgrounds

Final values require light/dark and accessibility testing.

## Wordmark

- clean sans-serif
- no handwritten family script
- no childcare bubble font
- in-app typography remains system typography for v1

## Tone of voice

Good:

- `4 Dinge erkannt. Bitte kurz prüfen.`
- `Für morgen fehlt noch eine Vorbereitung.`
- `Die Datei ist gespeichert. Die Analyse konnte noch nicht abgeschlossen werden.`

Bad:

- `✨ Magie erledigt! Deine Super-KI hat 4 Tasks gezaubert!`
- guilt-driven copy
- gamified organization scores

The product informs and assists; it does not judge the household.

## Current brand decision

Do **not** block implementation on the final public name. Use `Family Life OS` only as an internal repository/codename until a stronger, cleared brand is selected.
