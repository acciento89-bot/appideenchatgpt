# Family Organizer — Brand Direction v0.1

Status: DIRECTION LOCKED, PUBLIC NAME OPEN
Date: 2026-08-18

## 1. Brand job

The brand must make a parent think:

> This will make our everyday life calmer.

It must not communicate:

- surveillance
- parenting judgement
- childish gamification
- corporate project management
- generic AI magic
- yet another shared calendar

The product promise is functional calm: incoming family information becomes a clear, shared plan with less manual administration.

## 2. Brand personality

Primary traits:

- calm
- capable
- warm
- trustworthy
- clear
- discreet
- modern

Secondary traits:

- intelligent, but not showy
- friendly, but not cute
- premium, but not luxury
- family-oriented, but not baby-oriented

## 3. Positioning language

Internal product thesis:

`Family Life OS`

This phrase is **not available as a distinctive public positioning**, because current competitor Famiqo already publicly uses `Family Life Operating System`.

Public copy must therefore emphasize the workflow rather than the OS metaphor.

Preferred message territory:

- `Alles, was bei eurer Familie ankommt. Automatisch organisiert.`
- `Aus Elternbriefen, Nachrichten und Terminen wird euer gemeinsamer Plan.`
- `Weniger organisieren. Mehr Überblick.`
- `Familienalltag rein. Klarer Plan raus.`

Avoid generic claims:

- `Der smarte Familienplaner`
- `Alles für deine Familie`
- `AI Family Assistant`
- `Family OS`
- `Die ultimative Familien-App`

## 4. Naming principles

A strong name should:

- be pronounceable in German and English
- be 2–4 syllables
- work without `AI` in the name
- not be limited to calendar or chores
- not sound like a daycare/school-only tool
- not imply surveillance/location tracking
- allow a simple app-icon monogram or symbol
- ideally support a `.de` and/or sensible global domain later
- pass App Store, web and trademark collision checks before locking

### Naming territory A — calm coordination

Abstract names that suggest togetherness/flow without saying `family`.

Pros:

- broader long-term brand
- less generic
- easier premium positioning

Cons:

- product purpose needs subtitle/store copy

### Naming territory B — household/family signal

Names with a subtle family/kin/home root.

Pros:

- purpose clearer immediately

Cons:

- highly crowded; many obvious combinations already exist

### Naming territory C — Kamilunavo portfolio extension

A Kamilunavo-derived consumer brand extension can be considered if it passes trademark/product confusion checks.

Example territory only, not locked:

- `Navo Family`
- another `Navo...` sub-brand

Risk: `NAVO` is already used by unrelated software/products, including a current Dreame NAVO app, so exact clearance remains required.

## 6. Name-lock procedure

Before selecting a public name:

1. exact App Store search
2. Google/web exact-term search
3. EUIPO search
4. DPMA search
5. relevant international trademark search where practical
6. domain/social handle check
7. pronunciation/spelling test in DE + EN
8. App Store subtitle test
9. icon/wordmark test

No name is considered cleared merely because an exact App Store hit is absent.

## 7. Visual identity direction

### Core metaphor

The visual system should represent **many loose pieces becoming one organized family plan**.

Useful abstract motifs:

- converging paths
- grouped tiles becoming one shape
- a soft orbit around a center
- folded/incoming sheet transforming into a check/plan
- connected but distinct household members

Avoid:

- literal cartoon house + heart
- mother/father/children stick figures
- robot/AI sparkle as the main logo
- calendar page as primary icon
- checklist as primary icon
- location pin

The product is broader than any of those single functions.

## 8. App icon direction

### Preferred direction: `Gather -> Order`

A bold, simple symbol with 2–3 rounded pieces flowing into one centered organized form.

Requirements:

- recognizable at small size
- no text
- no tiny details
- strong silhouette
- works in light, dark and tinted icon appearances
- layered enough to benefit from modern iOS icon rendering without depending on glass effects

### Alternate direction: `Shared Orbit`

Three subtle nodes/rounded forms around a calm center, suggesting separate family members coordinating around shared information.

Risk: can become too generic/social-network-like if overcomplicated.

### Rejected direction: `House + Checkmark`

Too generic and instantly looks like chores/home management.

## 9. Color direction

Final brand palette is not locked yet.

Preferred territory:

- one calm primary brand hue
- one warmer supporting hue
- semantic family-member accents separate from the brand primary
- neutral system backgrounds

Do not make the global brand palette the same as member identity colors.

Possible palette mood to prototype:

- deep muted blue/indigo family for trust and structure
- warm amber/coral supporting note for human warmth
- restrained neutral backgrounds

Final values must be tested in light/dark mode and accessibility contrast before locking.

## 10. Wordmark direction

- clean sans-serif
- no handwritten family script
- no rounded-childcare bubble font
- typography should sit comfortably beside Apple's system UI rather than fight it

Inside the app, use system typography. A custom display face is not required for v1.

## 11. Tone of voice

### Good

`4 Dinge erkannt. Bitte kurz prüfen.`

`Für morgen fehlt noch eine Vorbereitung.`

`Diana übernimmt das Abholen.`

`Die Datei ist gespeichert. Die Analyse konnte noch nicht abgeschlossen werden.`

### Bad

`✨ Magie erledigt! Deine Super-KI hat 4 Tasks gezaubert!`

`Du hast vergessen, die Klassenfahrt zu bezahlen.`

`Deine Familie ist heute zu 78 % organisiert.`

The product informs and assists; it does not judge the household.

## 12. Current brand decision

Do **not** block product implementation on the final public name.

Use `Family Life OS` only as an internal repository/codename until a stronger, cleared brand is selected. The first UI prototype should use a neutral temporary display name so typography/layout is not designed around a name that may be discarded.
